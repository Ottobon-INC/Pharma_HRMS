# Orca Labs Pharma HRMS — Android App

## What is this folder?

`android-app/` is the **isolated Capacitor Android wrapper** for the Pharma HRMS web application.

It sits inside the main `Pharma_HRMS/` project as a dedicated Android development workspace. The web UI lives in the parent — this folder only contains the bridge, native plugins, and Kotlin services.

---

## Folder Structure

```
android-app/
├── package.json              ← Capacitor + plugin dependencies
├── capacitor.config.ts       ← Capacitor config (webDir: '../dist')
├── README.md                 ← This file
│
├── src-patches/              ← React patches to add to the PARENT src/
│   ├── platform.ts           → copy to: src/lib/platform.ts
│   ├── camera-service.ts     → copy to: src/lib/services/camera-service.ts
│   ├── geolocation-service.ts → copy to: src/lib/services/geolocation-service.ts
│   └── useAndroidBackButton.ts → copy to: src/hooks/useAndroidBackButton.ts
│
├── android-templates/        ← Kotlin/XML templates for android/ folder
│   ├── AndroidManifest.xml   → reference for android/app/src/main/
│   └── kotlin/
│       ├── MainActivity.kt   → android/.../MainActivity.kt
│       ├── EnhancedCameraPlugin.kt → android/.../plugins/
│       └── LocationForegroundService.kt → android/.../services/
│
├── scripts/
│   └── build-android.ps1     ← Full build + sync automation
│
├── assets/                   ← Source images for Capacitor Assets tool
│   ├── icon.png              ← 1024×1024, no transparency (ADD MANUALLY)
│   └── splash.png            ← 2732×2732, centered logo (ADD MANUALLY)
│
└── android/                  ← Generated by `npx cap add android` (DO NOT edit manually)
    └── [full Gradle/Kotlin project]
```

## Quick Start

### Step 1 — Install dependencies
```bash
cd android-app
npm install
```

### Step 2 — Build the web app (parent project)
```bash
npm run build:web
# This runs: cd .. && npm run build
```

### Step 3 — Initialize Android (first time only)
```bash
npx cap add android
```

### Step 4 — Sync
```bash
npx cap sync android
```

### Step 5 — Open Android Studio
```bash
npx cap open android
```

## Daily Development Workflow

```bash
# After changing any React/Vite code in the parent:
npm run android:debug
# = build:web + cap:sync + cap:run
```

## Relationship to Parent Project

```
Pharma_HRMS/          ← Web app (React + Vite)
├── src/              ← React source (add patches from src-patches/)
├── dist/             ← Vite build output ← THIS is what Android loads
└── android-app/      ← YOU ARE HERE
    └── android/      ← Gradle project opened in Android Studio
```

> **The `dist/` folder is the bridge.**
> - `npm run build` (in parent) → updates `dist/`
> - `npx cap sync android` (in android-app) → copies `dist/` into the Android WebView assets
